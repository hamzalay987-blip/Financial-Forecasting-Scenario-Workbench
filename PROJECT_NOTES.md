# Project notes: Financial Forecasting Scenario Workbench

**Business problem:** Planning teams need an interpretable forecast baseline before attempting complex prediction models.

**Design:** Use average month-over-month change with scenario multipliers and a basic holdout error estimate.

**Interview discussion:** Explain schema assumptions, late data/duplicate behavior, controls, expected tradeoffs, and what would change at enterprise scale.

**Suggested next feature:** Add sample-sized integration tests or a docker-compose service when the implementation is ready.
